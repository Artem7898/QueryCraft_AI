## Среда выполнения

Веб-интерфейс состоит из статических HTML, CSS и JavaScript в `frontend/public/`.
Uvicorn запускает API FastAPI на Python 3.12 или 3.13. При локальной разработке интерфейс работает на
порту 3000, API — на порту 8000. Node.js и npm нужны для проверок. Браузер
загружает приложение напрямую. [Страница приложения](../frontend/public/index.html)

`create_app()` создаёт приложение, принимает настройки и позволяет подставить
HTTP-транспорт в тестах. Каждый жизненный цикл ASGI создаёт асинхронный клиент
HTTPX с пулом соединений, счётчик генераций и действующий предел длины описания.
В пуле до 20 соединений, из них до 10 могут оставаться открытыми для повторного
использования. Оба максимума ограничены значением `MAX_REQUESTS_PER_MINUTE`.
При остановке приложение закрывает клиент и соединения.
[Фабрика приложения](../backend/app/main.py) · [Состояние процесса](../backend/app/runtime.py)

## Как обрабатывается запрос генерации

1. Браузер отправляет JSON с описанием, необязательным контекстом схемы,
   выбранным диалектом, сложностью и языком
   на `POST /api/v1/generate`. Промежуточный слой CORS обрабатывает
   предварительные запросы и определяет, каким источникам браузер разрешит
   прочитать ответ.
   [Обработка запроса в браузере](../frontend/public/assets/js/main.js)
2. Маршрут учитывает запрос в фиксированном 60-секундном окне процесса API.
   При чтении тела он считает байты до разбора JSON. Лимит составляет 64 КиБ.
   Запрос с ошибочным JSON или превышенным размером занимает выделенное ему
   место в квоте. [Маршрут генерации](../backend/app/api/v1/endpoints/query.py)
3. Pydantic удаляет пробельные символы по краям описания, проверяет поля и
   отклоняет неизвестные. После валидации схемы обработчик проверяет длину
   описания по настройкам приложения. [Схемы API](../backend/app/models/schemas.py)
4. В деморежиме приложение подставляет пример про пользователей, заказы или
   универсальный пример для выбранного диалекта. При генерации описание и
   контекст схемы входят в сообщение пользователя. Диалект, сложность и
   требования к пояснению передаются в системном сообщении. HTTPX отправляет
   запрос на OpenAI-совместимый маршрут `/chat/completions` выбранного
   провайдера. OpenAI получает параметр `max_completion_tokens`, Bytez и
   Ollama получают `max_tokens`.
   [Сервис генерации](../backend/app/services/ai_service.py)
5. Сервис извлекает первый результат и проверяет его синтаксис через SQLGlot
   для PostgreSQL, MySQL и SQLite. Для MongoDB применяются парсер JavaScript
   и проверка структуры команды оболочки. Ответ API содержит также признак
   источника `source` (`live` или `demo`) и имя провайдера для
   сгенерированного результата. Браузер отображает запрос и пояснение как текст.
   [Сервис генерации](../backend/app/services/ai_service.py)
   [Проверка диалекта](../backend/app/services/query_validation.py)
   [Отображение результата](../frontend/public/assets/js/main.js)

## Настройки и ограничения

API читает регистрозависимые имена переменных окружения и файл `.env` из
рабочего каталога процесса. У переменных окружения приоритет. При запуске из
`backend/` используйте `backend/.env`. [Настройки](../backend/app/config.py)

| Настройка или ограничение | По умолчанию | Поведение |
| --- | --- | --- |
| `GENERATION_MODE` | `live` | В среде разработки можно явно выбрать `demo` для локальных примеров. |
| `GENERATION_PROVIDER` | `bytez` | Поддерживаются `bytez`, `openai` или `ollama`. |
| `BYTEZ_API_KEY` | Не задан | Ключ Bytez. При выборе Bytez прежнее значение `your_api_key_here` включает деморежим. |
| `QUERYCRAFT_OPENAI_API_KEY` / `OPENAI_API_KEY` | Не заданы | Ключ OpenAI. Переменная QueryCraft имеет приоритет. |
| `BYTEZ_API_URL` | `https://api.bytez.com/models/v2/openai/v1` | Требуется адрес HTTPS с хостом. Учётные данные, строка запроса и фрагмент в адресе запрещены. |
| `OLLAMA_API_URL` | `http://127.0.0.1:11434/v1` | HTTP разрешён на loopback. Для удалённого хоста нужен HTTPS. |
| `MODEL_NAME` | Зависит от провайдера | Имя модели для запроса к провайдеру и ответа API. |
| `API_TIMEOUT` | 30 секунд | От 5 до 120 секунд на отправку запроса и чтение ответа провайдера. |
| `ALLOWED_ORIGINS` | Локальные источники на портах 3000 и 8000 | JSON-массив или список через запятую. У каждого источника есть схема и хост, а при необходимости порт. |
| `MAX_QUERY_LENGTH` | 1 000 символов | Максимум от 3 до 1 000 символов после обрезки пробелов по краям. |
| `MAX_REQUESTS_PER_MINUTE` | 60 | Общая квота генерации для всех клиентов одного процесса API. Проверки состояния и предварительные запросы CORS проходят вне квоты. |
| `ENVIRONMENT` / `DEBUG` | `development` / `false` | В production нужны генерация моделью и отключённая отладка. Bytez и OpenAI требуют ключи. |
| `APP_NAME` | `QueryCraft AI` | Префикс заголовка OpenAPI. |
| Контекст схемы | Необязателен | До 3000 символов после обрезки пробелов по краям. |
| Тело входящего запроса генерации | 64 КиБ | Фиксированный предел байтов при чтении тела. |
| Тело ответа провайдера | 256 КиБ | Фиксированный предел байтов при потоковом чтении. Клиент запрашивает кодирование `identity`. |

## Ошибки и границы приложения

| Статус | Условие | Что проверить |
| --- | --- | --- |
| `413` | Тело запроса превышает предел размера. | Уменьшите JSON. |
| `422` | Ошибка JSON или валидации поля. | Сверьте путь к полю из ответа со схемой OpenAPI. |
| `429` | Исчерпана квота генерации процесса. | Повторите запрос через время из заголовка `Retry-After`. |
| `502` | Сбой провайдера, некорректный формат ответа или ошибка синтаксиса результата. | Проверьте выбранный сервис и модель. Для Ollama проверьте, что сервис запущен и модель установлена. |
| `503` | На сервере нет ключа выбранного облачного провайдера. | Задайте его ключ в окружении сервера и перезапустите API. |
| `504` | Истекло время обращения к провайдеру. | Проверьте соединение и `API_TIMEOUT`, особенно при первом запуске локальной модели. |

Публичные ошибки валидации скрывают значения полей. Ошибки провайдера
возвращаются с фиксированными сообщениями. Версионированный маршрут состояния
проверяет готовность API и сообщает имя модели без обращения к провайдеру.
API отправляет описание и контекст схемы выбранному сервису. Клиент передаёт
авторизацию только выбранному облачному провайдеру. Для Ollama на loopback
клиент игнорирует настройки прокси из окружения. Парсер проверяет синтаксис без подключения
к СУБД. API возвращает текст запроса, а соответствие целевой схеме
проверяет пользователь. [Ошибки и состояние API](../backend/app/main.py)
[Запрос к провайдеру](../backend/app/services/ai_service.py)

CORS управляет доступом браузера к ответам API. При размещении сервиса нужна
отдельная проверка прав доступа. Если нескольким процессам требуется единая
квота, её применяют на уровне шлюза.
[Состояние процесса](../backend/app/runtime.py)

## Фронтенд

`main.js` обрабатывает форму, проверяет состояние API, подсвечивает SQL и
копирует черновик. Язык и тема хранятся в `localStorage` браузера. Service
worker регистрируется и получает контроль над страницей в своей области.
Фронтенд и API получают ответы по сети. Страница подгружает Tailwind, Swiper и
Google Fonts из внешних CDN.
[Основной скрипт](../frontend/public/assets/js/main.js)

## Проверки и диагностика

Запустите тесты бэкенда, проверку и контроль форматирования Ruff, mypy, а также
Jest и ESLint по командам из быстрого запуска. Тесты API проверяют валидацию,
CORS, размер тела и работу квоты при одновременных запросах. Подставной
транспорт проверяет выбор провайдера, авторизацию, тайм-аут, некорректный ответ
и превышение предела его размера. Для интеграционной проверки запустите
локальную модель или настройте ключ и сетевой доступ к облачному сервису.
[Команды проверки](../README_RU.md#проверки)
[Тесты бэкенда](../backend/tests/) · [Тесты фронтенда](../frontend/tests/)

- Если браузер не видит API, проверьте `GET /api/v1/health` с компьютера, где
  открыт браузер, и адрес запроса в инструментах разработчика. Для размещения
  настройте базовый адрес в `main.js` и адрес проверки в `app-state.js`, если
  используете эту проверку. [Основной скрипт](../frontend/public/assets/js/main.js)
  [Менеджер состояния](../frontend/public/assets/js/app-state.js)
- Если прямой запрос к API проходит, а запрос браузера завершается ошибкой,
  сравните заголовок `Origin` с `ALLOWED_ORIGINS` и проверьте предварительный
  запрос `OPTIONS`. [Проверка CORS по HTTP](../backend/cors_test.py)
- Если страница отображается без стилей или карусели, проверьте загрузку
  ресурсов CDN в инструментах разработчика браузера.
  [Внешние ресурсы](../frontend/public/index.html)
- Если форма показывает демопример, проверьте `GENERATION_MODE` и прежнее
  демозначение Bytez. Перезапустите API после выбора провайдера. Если запуск
  с `ENVIRONMENT=production` завершается ошибкой, проверьте режим, `DEBUG`
  и ключ, если он требуется выбранному провайдеру.
  [Конфигурация](../README_RU.md#конфигурация)
